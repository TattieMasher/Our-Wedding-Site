# Wedding RSVP & Registry Platform

A polished full-stack web app I built to manage wedding guest RSVPs and a gift registry in one seamless experience.

## Portfolio Value
- Demonstrates end-to-end product ownership: UX, backend logic, and deployment-ready architecture.
- Shows practical Laravel + Livewire development with relational data modeling and transactional flows.
- Highlights my ability to ship real-world software that balances clean design with reliable functionality.

`Side-note: I think using PayPal.me was a pretty good way of avoiding the awkward "what can we get you as a gift" questions we kept getting asked!`

## Stack
Laravel, Livewire, Blade, MySQL, SCSS, Vite.
